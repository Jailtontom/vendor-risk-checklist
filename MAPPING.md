# Question mapping: version 1.3 → version 1.4

Version 1.4 (November 2026) shortened the checklist from 50 to 42 questions by combining eight pairs of overlapping questions, and renumbered the questions. This file shows where every version 1.3 question went, so earlier references (letters, articles, comments) can still be followed.

- Versions 1.2 and 1.3 remain available in this repository (PDFs and Git history).
- Questions refined with practitioner feedback in versions 1.2 and 1.3 (v1.3 numbers 4, 9, 31, 35, 38 and 46–50) keep their exact wording; only their numbers changed.
